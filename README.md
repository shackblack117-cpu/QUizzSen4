# Software Engineer Quiz

Website luyện tập Software Engineering bằng tiếng Việt, chạy trực tiếp trong trình duyệt.

## Chạy website local

1. Cài Node.js nếu máy chưa có.
2. Mở terminal tại thư mục dự án.
3. Chạy `npm run dev`.
4. Mở địa chỉ `http://localhost:5173` trong trình duyệt.

Dừng máy chủ bằng `Ctrl+C`. Không cần `npm install`; server dùng các module tích hợp sẵn của Node.js.

## Nội dung và tính năng

- Đủ 169 câu từ tài liệu tổng hợp: 22 câu Quizizz, 63 câu Quizlet và 84 câu SEN Full.
- Giữ câu trùng riêng theo từng nguồn, đúng với tài liệu.
- Luyện nhanh 10 câu, thi thử 20 câu hoặc chọn một nhóm nguồn.
- Câu trắc nghiệm có lựa chọn; câu điền đáp án có ô nhập và chấm theo đáp án trong tài liệu.
- Theo dõi kết quả, thời gian và điểm cao nhất bằng localStorage.
- Có thêm các trang ví dụ theo tuần, ôn tập và không gian soạn code.

Tiến độ học được lưu trong trình duyệt bạn đang dùng.
